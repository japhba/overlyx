01 / Model

Rotation and damping are separate ingredients

A two-dimensional state evolves under a constant linear operator. Damping α controls the envelope; ω sets the rotation rate.

\[\dot{\mathbf{x}}=\begin{pmatrix}-\alpha&-\omega\\\omega&-\alpha\end{pmatrix}\mathbf{x}\]

Eigenvalues: −α ± iω

Assumptions: linear, autonomous, deterministic.

03 / Interpretation

The real part of the eigenvalue decides stability

α > 0

Decay toward the fixed point. Perturbations shrink.

α = 0

Neutral cycles. The initial amplitude persists.

α < 0

Growth away from the origin. The fixed point is unstable.

Local linear stability alone does not prove global nonlinear stability.
