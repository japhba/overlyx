Diffusion erases small patterns first

Analytical model · Open methods

The question

How quickly does a spatial pattern disappear when its components diffuse?

The model

A one-dimensional field on a periodic domain. Constant diffusivity D; no forcing or advection.

\[\partial_t u = D\,\partial_{xx}u\]

Each Fourier mode evolves independently. Its spatial frequency sets its decay rate.

\[A_k(t)=A_k(0)e^{-Dk^2t}\]

Reproduce the figure

Plot exp(−s) and exp(−4s) for s from 0 to 3. Both start at unit amplitude. No fitted parameters.

The main finding

Double the spatial frequency.
Four times faster decay.

Small-scale structure smooths out before large-scale structure.

Analytical teaching example · not measured data

01 / Evidence

Same start, different lifetimes

Normalized mode amplitudes. Time is measured in the lifetime of the first mode, τ₁ = 1/(Dk₁²).

What this does not show

Variable diffusivity, boundaries and nonlinear coupling can change this picture. Test those assumptions before interpreting measured data.
