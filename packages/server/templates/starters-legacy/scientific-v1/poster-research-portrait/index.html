Calibration is more than a single score

01 / The question

When a forecast assigns probability p, does the event occur with frequency p? Reliability diagrams inspect this relationship directly.

02 / Definition

\[\mathbb{E}[Y\mid P=p]=p\]

Y is a binary outcome. P is its predicted probability. Calibration describes agreement, rather than how sharp the forecasts are.

03 / Inspect the whole curve

Analytical curves, not estimated data. The dashed identity is perfect calibration; the solid curve illustrates an underconfident forecast, with event frequency √p.

04 / Report uncertainty

With measured data, show bin counts and uncertainty intervals. Sparse bins can make an apparently smooth curve misleading.

05 / Go beyond calibration

A constant forecast at the base rate can be calibrated. Report discrimination and a proper score alongside reliability.

G. W. Brier, Verification of forecasts expressed in terms of probability (1950)
